客户端选择与官方下载

七八云强调客户端选择的灵活性。请根据设备系统下载对应加速器，再导入官方订阅链接。推荐使用开源或广泛验证的工具，从正规渠道获取安装包。

Windows

可选用 Clash for Windows 或 v2rayN。下载后创建配置或直接粘贴七八云订阅地址并更新节点。

macOS

ClashX、Clash Verge 或 Surge 均可。注意权限设置，导入订阅后选择规则模式。

Android

Clash Meta、v2rayNG 等。从应用商店或 GitHub 发布页获取，避免不明来源 APK。

iOS

Shadowrocket、Stash 或 Quantumult。需通过外区账户获取应用，导入七八云提供的订阅即可。

操作说明

获取订阅

在七八云选择套餐并完成开通后，您将收到专属机场订阅 URL。请妥善保存，该链接用于客户端自动拉取节点列表。

安装客户端

按照上一节客户端选择，完成安装并授予必要网络权限（如 VPN 配置、通知）。

导入并连接

打开客户端的订阅或配置页面，粘贴七八云订阅地址，点击更新。待节点加载完成后，可按延迟排序选择节点并开启连接。建议先测试本地网络，再切换至七八云节点。

日常使用

根据场景切换节点或规则。流量将在客户端或用户中心显示用量。遇到问题可通过套餐对应的工单渠道反馈。

常见问题

七八云是什么服务？

七八云是机场订阅与 VPN 网络加速服务，用户通过订阅链接在各类客户端中使用全球节点，实现更稳定的跨境访问。品牌定位为简洁的官方下载与订阅入口。

如何进行七八云客户端下载？

七八云不直接托管客户端安装包，而是推荐 Clash、v2ray 等主流工具的官方或商店版本。请根据设备类型在上文客户端选择章节查找对应软件，下载后导入订阅即可，这样更利于版本更新与安全性。

订阅链接导入失败怎么办？

请检查链接是否完整、客户端是否支持该订阅格式（通常为 Clash 或通用订阅）。尝试更换网络环境更新，或清除客户端缓存后重试。仍失败可联系对应套餐的支持渠道。

各套餐同时在线设备如何计算？

基础版最多 3 台设备同时使用节点，旗舰版 5 台，团队版 20 台。超出可能影响连接，建议合理分配或升级套餐。

流量用尽后还能使用吗？

当月额度用完后速度会受限或暂停加速功能，直至下个计费周期重置。可考虑升级到更高流量套餐。具体以开通时说明为准。

七八云支持哪些流媒体？

基础版提供基础解锁，旗舰版强调全节点原生解锁常见平台。实际效果随节点与平台策略变化，建议以实测为准，七八云会持续维护线路。
